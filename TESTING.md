# Проверка Смотрим TV 0.3.0

Дата: 17 октября 2026 года. Release versionCode 7. Android 9+, ARM 32/64 бит. Проверки Android выполнены на отдельном Android TV API 34 ARM64.

## Сборка и автоматические проверки

- Подписанная release-сборка выполнена успешно. Сертификат прежний; APK 0.3.0 успешно установлен через adb поверх 0.2.4 на отдельном эмуляторе. Каждый файл производственных assets при упаковке побайтно сверен с APK. Android lint: 0 ошибок, 13 предупреждений (те же категории, что в 0.2.4).
- 35 JVM-тестов: SourcesTest — 6, LiveChannelsTest — 6, TorrentBufferPolicyTest — 6, UpdateReleaseTest — 8, ProgrammeGuideTest — 6, SleepTimerTest — 3. Все прошли.
- 26 Android-тестов: прежние 21 проверки плеера, IPTV, голоса, трейлеров и обновлений; PlaybackFeaturesTest — 4, MainPlaybackControlsTest — 1. Все прошли отдельными прогонами.
- 6 Node-тестов: номера сезонов/серий, группировка и порядок файлов, выбор следующей серии, ранжирование качества/языка, устойчивый порядок каналов и отмена переноса, границы перемотки, смысл показателей диагностики. Все прошли. JavaScript проверен node --check.
- MainPlaybackControlsTest запускает реальную MainActivity и Media3 с локальным видео: подготовка, ограничение позиции перемотки, установка/отмена таймера и остановка плеера после истечения срока. Время истечения ускорено только в тесте.
- Android проверяет сохранение языка звука/субтитров и применение к новому плееру; XMLTV проверен на JVM и Android, включая запрет DTD и внешних сущностей.

Первый запуск Android-тестов столкнулся с прежней release-подписью в тестовом эмуляторе; тестовый пакет переустановлен. Первый новый тест XMLTV выявил неподдерживаемую Android SAX-функцию: необязательный флаг заменён совместимой настройкой с обязательным запретом DTD. Повторные проверки прошли. Нативный JVM TorrentStreamingTest отдельно в этой версии не запускался; торрент-поток проверен AndroidPlaybackTest.

## Проверка интерфейса с пульта

При фактическом viewport 1280×720 через интерфейс проверены:

- Перенос канала: OK → ↓ → OK → сохранить, порядок сохраняется после перезагрузки. В полном списке из 666 каналов → переносит на десять позиций и оставляет выбранную строку видимой; «Назад» возвращает её на прежнюю позицию. После закрепления → переводит сразу к сохранению из любой строки, ↑ возвращает к тому же каналу.
- Отдельный порядок избранных сохраняется независимо от общего. Выход из редактора через «Назад» отменяет несохранённые перестановки.
- Сезоны и серии, отдельная группа нераспознанных файлов, отметки просмотренного, выбор текущей и следующей серии. Исправлен первоначальный выбор группы «Другие видео» вместо первого сезона.
- Продолжение после выхода и перезагрузки, сохранение 01:02, одна карточка сериала после перехода к следующей серии. Отметка просмотренного убирает карточку из «Продолжить просмотр».
- Предпросмотр перемотки: 00:42 → 01:02 двумя нажатиями →, фактический seek отправляется после OK.
- Меню таймера, диагностика и выбор качества 4K; фокус сохраняется после настройки.
- CH+ учитывает сохранённый порядок; возврат к предыдущему каналу работает.

Стенд playback.html использует производственные HTML/CSS/JS и имитирует Android-мост. Его история отделена портом; настоящее видео и обновления на этом стенде не запускаются. Ошибок JavaScript при выполненных сценариях не обнаружено.

## Программа передач

Проверен реальный архив epg.pw: около 4,7 МиБ сжатых / 67,2 МиБ XML. В тестовом снимке 4078 определений каналов; после ограничения ближайшими сутками осталось 1657 каналов с передачами. Уверенно сопоставлены 65 из 666 встроенных каналов, включая «Пятницу», НТВ и РЕН ТВ. Количество зависит от обновления источника. Исправлено ошибочное совпадение российского НТВ с немецким NTV; региональные и сдвинутые версии не подставляются вместо основного эфира. Для неподтверждённых совпадений программа не показывается.

## Ограничения

Физический TCL 65P7K не использовался. Не проверены его конкретный пульт, настоящая многоязычная раздача и доступность каждой IPTV-ссылки. Распознавание сезонов зависит от имён файлов внутри выбранной раздачи; отдельные раздачи разных сезонов автоматически не объединяются в каталог сезонов. Языковые предпочтения применяются, когда дорожки имеют корректные метаданные; качество/язык в поиске определяются по названию раздачи и не гарантируют её доступность. Таймер останавливает просмотр и загрузку, но не выключает телевизор. Карточки домашнего экрана Google TV в этот релиз не входят.

## Повторение

См. ui-tests/README.md. JVM: выбранные шесть классов выше через :app:testDebugUnitTest --tests. Android: :app:connectedDebugAndroidTest с android.testInstrumentationRunnerArguments.class. JS: node --test ui-tests/features.test.cjs. Сборка: :app:assembleRelease :app:lintRelease.

# Проверка Смотрим TV 0.2.4

Дата: 17 октября 2026 года. Release versionCode 6. Изменены HTML/CSS/JavaScript интерфейса и версия приложения; нативный плеер, источники и механизм обновления сохранены.

## Проверка UI/UX

Проверка через интерфейс в браузере при фактическом viewport 1280×720, теми же стрелками, OK и «Назад», которые использует WebView на ТВ. Локальный стенд ui-tests/ux.html использует производственные assets и имитирует только Android-мост. Воспроизведение, речь, сеть источников и установка обновления на стенде не выполняются.

Проверены сценарии:

- Главная → «Смотреть» сразу открывает варианты просмотра.
- Поиск: ↓ из строки ставит фокус на первую букву; → в конце строки переводит к микрофону. После распознавания фокус на «Найти видео».
- Вставка буквы в середине запроса, удаление слева от каретки и сохранение остальных букв. Для слова «Выживалити» измерены координаты каждой буквы во всех 10 перемещениях каретки влево: сдвиг отсутствует (допуск 0,01 CSS px). Вставка «Б» дала «ВыживБалити», удаление восстановило исходное слово.
- Запрос без результатов и ошибка источника: есть понятная причина, повторный поиск и редактирование с сохранённым запросом.
- Список из 12 вариантов, длинные названия в две строки, последний вариант без раздающих. Последняя строка после прокрутки полностью видна; нижняя граница 607 px при подсказках с 680,67 px.
- Плеер: два нажатия «Назад» возвращают к выбранной строке; продолжение с главной и «Другой вариант» после ошибки восстанавливают исходный поиск.
- ERROR_CODE_IO_BAD_HTTP_STATUS показывается понятным сообщением. Исходная ошибка доступна в «Подробностях»; после закрытия фокус возвращается на ту же кнопку.
- Поиск канала оставляет результаты в списке. Два нажатия → и OK добавляют канал в избранное. Ссылка из общего избранного открывает избранные телеканалы.
- Пустое избранное: подсказка, кнопка выбора фильма, отсутствие пустых фильтров. Пустой список избранных каналов содержит переход ко всем каналам.
- Каталог: после переходов на вторую и третью страницы фокус остаётся на стрелке. Карточки в два ряда заканчиваются на 648,67 px и не перекрывают подсказки. Названия до двух строк.
- Очистка истории требует подтверждения, по умолчанию выбрана «Отмена». Стрелки не выходят из диалога; «Назад» сохраняет историю и возвращает фокус. Данные пользователя не очищались.
- Настройки буфера: понятное объяснение, все варианты и кнопка «Назад» помещаются на экран; отмена возвращает фокус.

JavaScript проверен node --check. В тестовом интерфейсе ошибок JavaScript не зарегистрировано. Подписанная release-сборка и Android lint выполнены: 0 ошибок, 13 предупреждений (как в предыдущей версии).

Физический TCL, системная клавиатура, настоящий микрофон и настоящее видео в этой UI-проверке не использовались. Автоматические нативные тесты 0.2.3 ниже — результаты предыдущей версии, а не нового прогона. Отдельное изменение размера окна до Full HD не подтвердилось браузером; фактическая визуальная проверка выполнена при 1280×720.

## Как повторить

См. ui-tests/README.md. Файлы тестового моста находятся вне app/src/main/assets и не попадают в APK. Для сборки: `./gradlew :app:assembleRelease :app:lintRelease`.

# Проверка Смотрим TV 0.2.3

Дата: 17 октября 2026 года. Release versionCode 5, Android 9+, targetSdk 35, ARM 32/64 бит. Среда: macOS ARM64, JDK 17, Gradle 8.11.1, Android TV API 34 ARM64.

## Сборка и установка

- Подписанный release APK собран. Android lint: 0 ошибок, 13 предупреждений (версии зависимостей, WebView/fullscreen/backup API и оценка свободного дискового места).
- Проверена установка предыдущего release APK 0.2.2, затем APK 0.2.3 командой adb install -r на отдельном эмуляторе: успешно.
- Сертификат release прежний; ключ и пароли в репозиторий и архив не включены.
- При упаковке каждый файл app/src/main/assets побайтно сравнивается с APK; тестовые мосты UI и нативный libtorrent4j в пользовательский APK не входят.

## Автоматические тесты

JVM: SourcesTest — 6, LiveChannelsTest — 6, TorrentBufferPolicyTest — 6, UpdateReleaseTest — 8, TorrentStreamingTest — 1. Все 27 тестов прошли несколькими прогонами.

Новые 8 тестов проверяют числовое сравнение версий (0.2.10 > 0.2.9), отсутствие отката и предложения текущей версии, исключение черновиков/prerelease, единственный готовый APK, ограничения URL/размера/контрольной суммы, разрешённые переадресации GitHub, ограничение текста изменений. Метаданные релиза не исполняются как код.

Первый общий JVM-прогон завершился аварийно с кодом 139 внутри нативного торрент-теста. После завершения эмулятора отдельный повтор TorrentStreamingTest прошёл за 26 секунд. 26 остальных JVM-тестов прошли отдельным прогоном. Торрент-движок в этой версии не менялся.

Android: LivePlaybackTest — 2, AndroidPlaybackTest — 2, TrailerLauncherTest — 4, VoiceSearchTest — 3, ApkVerificationTest — 10. Все 21 проверка прошла несколькими прогонами; последний прогон ApkVerificationTest завершён без ошибок. Всего успешно выполнено 48 тестов JVM и Android.

Проверки обновления: принятие более новой версии с тем же сертификатом, отказ при другой подписи/версии/пакете, повреждённый APK, запрет установки текущей версии, сохранение настройки автоматической проверки, ограничение FileProvider папкой updates, удаление APK и его фрагмента по событию MY_PACKAGE_REPLACED без удаления других файлов, истечение срока хранения отменённого обновления через сутки.

Для проверки различающихся подписей используются реальные сертификаты тестового приложения и системного Android; номер следующей версии в проверке политики задаётся тестом. Три первоначально не прошедших теста использовали общий кэшированный PackageInfo; тестовые данные исправлены на независимые копии, все 8 первоначальных проверок повторно прошли. Позже добавлены две проверки очистки.

Остальные 11 Android-тестов прошли: HTTP 404 с запасным IPTV-потоком, ограничение повторов при 403, декодирование потока TorrServer/Media3 с буферами 96 и 256 МиБ и стартом с 10 секунд, Intent/результаты трейлеров и голоса. Эти тесты используют локальное видео и локальные источники.

## Интерфейс

В обычном браузерном предпросмотре проверены раздел в настройках, ручная проверка и переключатель автоматической проверки. В ui-tests/updates.html проверены уведомление о доступной версии, описание изменений, прокрутка текста стрелками пульта, переходы available → downloading → ready и повторный запуск установки. Прогресс обновляется без пересоздания экрана на каждом фрагменте загрузки. Текст с HTML-тегами показывается как текст.

Тестовый экран явно помечен и имитирует Android-мост; настоящие APK он не устанавливает. Сборка содержит системный установщик через FileProvider и ACTION_VIEW.

## Ограничения проверки

Физический TCL 65P7K, разрешение установки через его системное меню и подтверждение установки пультом не проверены. На эмуляторе установка поверх предыдущей версии выполнена через adb, а не через полный экранный сценарий установщика. Полный путь скачивание GitHub → системное окно → перезапуск приложения на телевизоре ещё требует проверки. Механизм проверки подписи/версии, FileProvider и очистки проверен инструментальными тестами.

Нет фоновой тихой установки: пользователь нажимает «Скачать и обновить», затем подтверждает системную установку. Если приложение ушло в фон или начался просмотр, установщик не открывается автоматически. Для загрузки требуется около трёх размеров APK плюс 32 МиБ свободного места под файл, staging и распаковку. Недоступность GitHub не блокирует просмотр.

Отменённый готовый APK хранится не более суток до следующей проверки состояния: при запуске или открытии раздела обновлений просроченный файл удаляется. Фоновый таймер на выключенном приложении не запускается. После успешной установки системное событие замены приложения удаляет APK сразу; очистка при следующем запуске остаётся резервным механизмом.

## Повторение

```sh
./gradlew :app:testDebugUnitTest --tests 'ru.smotrim.tv.UpdateReleaseTest'
ANDROID_SERIAL=тестовый_эмулятор ./gradlew :app:connectedDebugAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.class=ru.smotrim.tv.ApkVerificationTest
./gradlew :app:assembleRelease :app:lintRelease
```

Подготовка нативного JVM-теста описана в README.md. Для проверок используйте отдельное тестовое устройство, поскольку debug и release имеют разные подписи.
