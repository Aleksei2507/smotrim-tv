## Интерфейс

В обычном браузерном предпросмотре проверены раздел в настройках, ручная проверка и переключатель автоматической проверки. В ui-tests/updates.html проверены уведомление о доступной версии, описание изменений, прокрутка текста стрелками пульта, переходы available → downloading → ready и повторный запуск установки. Прогресс обновляется без пересоздания экрана на каждом фрагменте загрузки. Текст с HTML-тегами показывается как текст.

Тестовый экран явно помечен и имитирует Android-мост; настоящие APK он не устанавливает. Сборка содержит системный установщик через FileProvider и ACTION_VIEW.

## Ограничения проверки

Физический TCL 65P7K, разрешение установки через его системное меню и подтверждение установки пультом не проверены. На эмуляторе установка поверх предыдущей версии выполнена через adb, а не через полный экранный сценарий установщика. Полный путь скачивание GitHub → системное окно → перезапуск приложения на телевизоре ещё требует проверки. Механизм проверки подписи/версии, FileProvider и очистки проверен инструментальными тестами.

Нет фоновой тихой установки: пользователь нажимает «Скачать и обновить», затем подтверждает системную установку. Если приложение ушло в фон или начался просмотр, установщик не открывается автоматически. Для загрузки требуется около трёх размеров APK плюс 32 МиБ свободного места под файл, staging и распаковку. Недоступность GitHub не блокирует просмотр.

Отменённый готовый APK хранится не более суток до следующей проверки состояния: при запуске или открытии раздела обновлений просроченный файл удаляется. Фоновый таймер на выключенном приложении не запускается. После успешной установки системное событие замены приложения удаляет APK сразу; очистка при следующем запуске остаётся резервным механизмом.
