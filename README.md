# Смотрим TV · 0.2.3

Приложение для Android TV / Google TV, подготовленное для TCL 65P7K. Управление рассчитано на обычный пульт: стрелки, OK и «Назад». Android 9 и выше, ARM 32/64 бит.

## Установка на TCL

1. Скопируйте `Smotrim-TV-0.2.3.apk` на USB-флешку и подключите её к телевизору.
2. Откройте APK через файловый менеджер на телевизоре. Если система запросит разрешение на установку из этого приложения, разрешите его и снова откройте APK. Названия пунктов зависят от версии Google TV.
3. Нажмите «Установить». Приложение «Смотрим» появится в списке приложений телевизора.
4. Подключите телевизор к интернету. Для крупных раздач лучше стабильный Ethernet или Wi-Fi 5 ГГц.

Можно передать APK и другим привычным способом. При включённой отладке Android установка с компьютера: `adb install -r Smotrim-TV-0.2.3.apk`. Обновление подписано прежним ключом: устанавливайте поверх версии 0.1.0, 0.2.0, 0.2.1 или 0.2.2, чтобы сохранить избранное и историю.

## Обновления через GitHub

[Скачать актуальный APK](https://github.com/Aleksei2507/smotrim-tv/releases/latest) · [Репозиторий](https://github.com/Aleksei2507/smotrim-tv)

Версию 0.2.3 нужно один раз установить поверх предыдущей вручную. Начиная с неё приложение при запуске проверяет GitHub Releases не чаще раза в сутки. Автоматическую проверку можно отключить. Ручная проверка всегда доступна: **Настройки → Обновления приложения → Проверить сейчас**.

Если новая версия найдена, появляется кнопка с её номером. На странице обновления показаны изменения и размер APK. «Скачать и обновить» загружает файл, проверяет размер, SHA-256 (если GitHub его передал), имя пакета, номер версии и подпись. При первом обновлении Android попросит разрешить установку для «Смотрим»; после возврата откроется системный установщик. Подтвердите установку пультом. Если разрешение не выдано или установка отменена, файл остаётся доступен через кнопку «Установить обновление».

Проверка обновлений не прерывает видео. Загрузка начинается только после нажатия кнопки. Если к окончанию загрузки приложение закрыто или уже идёт просмотр, установщик сам не открывается: завершите просмотр и установите обновление из настроек. История, избранное и настройки сохраняются при установке поверх предыдущей версии. После успешного обновления APK и временный фрагмент удаляются по системному событию замены приложения; очистка при следующем запуске служит резервным механизмом. Если установка отменена, готовый APK хранится сутки: при следующем запуске или открытии обновлений просроченный файл автоматически удаляется. Незавершённые загрузки удаляются при ошибке или следующем запуске. Автоматическая установка без системного подтверждения в этой версии не используется.

Для проверки и загрузки нужен только доступ к публичному GitHub. Вход в аккаунт и токен на телевизоре не нужны. Приложение обращается к фиксированному репозиторию Aleksei2507/smotrim-tv; переадресации разрешены только на серверы GitHub. Новое разрешение REQUEST_INSTALL_PACKAGES используется исключительно для обновления самого приложения.

### Выпуск следующей версии

1. Увеличьте versionCode и versionName в app/build.gradle, обновите номер в интерфейсе и соберите `./gradlew :app:assembleRelease` с прежним локальным ключом. Ключ `.signing` не публикуйте и не заменяйте.
2. Подготовьте файл изменений в Markdown и обновите TESTING.md. Синхронизируйте проверенные исходники с репозиторием.
3. Выполните приведённую команду сначала с `--dry-run`, затем без этого флага. Она проверит подпись APK и совпадение ресурсов с исходниками, соберёт архив исходников без ключа, создаст черновик релиза, загрузит все файлы и только после этого сделает релиз видимым телевизорам.

```sh
python3 tools/publish_release.py \
  --build-tools /путь/к/android-sdk/build-tools/35.0.0 \
  --notes /путь/к/изменениям.md \
  --torrserver-source /путь/к/TorrServer-MatriX.147-source.tar.gz \
  --dry-run
```

Нужны авторизованный `gh`, Android SDK и JDK (JAVA_HOME). APK берётся из `app/build/outputs/apk/release/app-release.apk`. Публикация идёт в GitHub Releases с тегом вида `v0.2.4`; внутри релиза должен быть один универсальный `.apk`. Черновики и предварительные релизы телевизор не предлагает. Скрипт не перезаписывает уже опубликованную версию. Ключ подписи остаётся на компьютере; секреты в GitHub Actions для этой схемы не нужны.

## Что уже работает

- Телеканалы: встроенный русский M3U-список iptv-org, поиск, фильтры и свой M3U по ссылке. Поддерживаются заголовки User-Agent и Referer, заданные плейлистом. При отказе сервера плеер пробует запасной адрес того же эфира и запоминает рабочий источник.
- Фильмы: популярный каталог Cinemeta, карточки и избранное. Поиск из каталога и бокового меню сразу ищет раздачи фильмов, сериалов и шоу по всему доступному ответу JacRed, Rutor и APIBay.
- Трейлеры: кнопка в карточке фильма открывает ролик из Cinemeta в YouTube. Если роликов несколько, можно выбрать нужный; повторяющиеся ссылки объединены. Если ссылки нет, кнопка недоступна и показано пояснение.
- Раздачи: общий поиск через JacRed, Rutor и APIBay, объединение одинаковых magnet-ссылок, сортировка по сидам, качество и размер перед запуском.
- Встроенный TorrServer MatriX.147 подгружает нужные части видео в RAM-буфер. В настройках доступны 96, 128, 256 и 512 МБ; по умолчанию 96 МБ. Android Media3 воспроизводит поток. Отдельно устанавливать сервер или держать компьютер включённым не нужно.
- Можно открыть свою magnet-ссылку. Поле также принимает прямой HTTP(S)-адрес файла `.torrent`.
- Пауза, перемотка, доступные аудиодорожки и субтитры. Если раздача содержит несколько видео, приложение предлагает выбрать файл.

В приложении нет рекламных SDK и аналитики. В самих телеканалах может идти эфирная реклама. Трейлеры открываются во внешнем YouTube, где возможна реклама сервиса.

## Управление

При переключении страниц в «Фильмах» и «Избранном» выделение остаётся на нажатой стрелке. Можно нажимать OK несколько раз подряд. На краю списка выделяется доступная стрелка в обратную сторону.

Трейлер открывается сначала через YouTube для TV, затем через другой установленный обработчик ссылки, если TV-приложение недоступно. Кнопка «Назад» возвращает в карточку или список трейлеров, пока Android сохраняет приложение в памяти. Если YouTube или браузера нет, появится подсказка. Ролики могут быть на другом языке, удалены или недоступны в сети/регионе телевизора. Трейлеры доступны для карточек с метаданными Cinemeta; произвольные результаты поиска раздач пока не сопоставляются с карточками фильмов.

| Кнопка | Действие |
| --- | --- |
| Стрелки | Перемещение между кнопками и карточками |
| OK | Выбор; в видео — показать управление |
| Назад | Предыдущий экран; в видео — сначала скрыть панель, затем выйти |
| Влево / вправо в видео при скрытой панели | Перемотка на 10 секунд |
| Кнопки «Звук» / «Субтитры» | Выбор дорожек из самого видео |

В разделах «Фильмы» и «Телеканалы» есть отдельная кнопка поиска. Телеканалы фильтруются прямо на своей странице: найденный канал можно сразу смотреть или добавить в избранное. Переключатель телеканалов в общем поиске ведёт на эту же страницу. «Назад» на странице с запросом сначала сбрасывает поиск. Для каналов работают часть названия и транслитерация; для ряда английских названий добавлены русские варианты.

На главной «Выбрать раздачу» сразу открывает список; отдельная кнопка «О фильме» открывает карточку. Кнопка «Раздачи» в плеере открывает раздачи текущего фильма даже после продолжения с главной или ошибки. Для новых записей истории сохраняется исходный запрос поиска; старые записи используют сохранённое название раздачи. Длинные названия в «Продолжить просмотр» ограничены двумя строками с многоточием, время остаётся видимым.

В строке поиска фильмов есть курсор. Кнопки со стрелками двигают его; стрелки пульта влево/вправо на самой строке делают то же. Буквы вставляются в позицию курсора; кнопка ⌫ удаляет букву слева. OK на строке открывает системную клавиатуру с введённым текстом. Также доступна экранная клавиатура с русскими буквами, латиницей и цифрами.

Кнопка микрофона есть в поиске фильмов и на странице телеканалов. Она вызывает системное распознавание речи на русском языке. Для фильмов результат можно исправить, затем нажать «Найти раздачи»; для каналов список фильтруется сразу. Если распознавание недоступно, показана подсказка. Микрофон, приложение распознавания и его разрешения должны работать на телевизоре. «Смотрим» не записывает звук самостоятельно и не добавляет разрешение RECORD_AUDIO; обработку выполняет выбранное системой приложение распознавания, которое может использовать сеть.

Для поиска шоу откройте «Фильмы» → «Поиск фильмов и шоу», введите, например, «Выживалити» и нажмите «Найти раздачи». Поиск обращается напрямую к торрент-источникам и не ограничен популярными карточками Cinemeta. Можно уточнить сезон или выпуск. Результаты объединяются по torrent-hash и сортируются по числу сидов; полнота зависит от ответа и ограничений каждого источника. У раздач из поиска тоже сохраняются выбранный видеофайл и позиция просмотра. Часть описаний карточек остаётся на английском.

## Подключение телеканалов

Встроенный список автоматически обновляется при запуске; при отсутствии сети используется сохранённый. Свой плейлист автоматически не заменяется. Кнопка «Обновить телеканалы» в настройках загружает встроенный список iptv-org.

Для встроенных каналов приложены 1486 адресов потоков из базы iptv-org. При запуске доступно до шести подходящих адресов; рабочий адрес запоминается и используется первым. Варианты качества SD/HD одного канала могут заменять друг друга; региональные версии и эфиры со сдвигом +1/+2/+4 не смешиваются. Для своего плейлиста используются только адреса из него. База запасных адресов обновляется в фоне не чаще раза в сутки.

При HTTP 401/403/404/410 адрес повторно не запрашивается: проверяется следующий источник. Для временного сетевого сбоя предусмотрено ограниченное повторное подключение. На начало передачи от каждого адреса отводится до 15 секунд. Если все варианты недоступны, приложение показывает HTTP-код, объяснение и кнопку «Повторить». Географические ограничения и отключённый эфир этим исправлением не устраняются.

## Память и доступность

Размер фильма больше не сравнивается со свободным местом на телевизоре: видео не записывается целиком во внутреннюю память. В «Настройки → Буфер торрентов» можно выбрать 96, 128, 256 или 512 МБ. Выбор сохраняется и применяется со следующего запуска фильма. Общий расход RAM выше из-за декодера и самого движка. Просмотренные части освобождаются по мере необходимости. На диске остаются небольшие временные настройки и метаданные, удаляемые при закрытии просмотра.

Перед запуском проверяются общий объём и доступная оперативная память. Если выбранный размер не помещается с запасом для системы и движка, приложение снижает его до 256, 128 или 96 МБ и сообщает об этом. Выбор в настройках сохраняется; фактический лимит отображается в плеере. Проверка памяти — оценка на момент запуска, а не гарантия отсутствия системной нехватки RAM. Более крупный буфер сглаживает кратковременные просадки скорости, но не исправляет медленную раздачу или неподдерживаемый кодек.

Позиция сохраняется каждые 5 секунд и при выходе. «Продолжить просмотр» открывает прежнюю раздачу и выбранный файл с сохранённого времени. Буфер наполняется заново около нужного момента; плеер также может запросить служебные данные из начала или конца файла. Ждать скачивания всего фильма с начала не требуется. Резкое выключение питания может потерять последние несколько секунд позиции.

Доступность каналов и раздач зависит от источника, сети телевизора и числа раздающих. Список каналов не означает, что каждый поток работает постоянно. Нет программы передач, архива эфира или воспроизведения DRM-защищённых сервисов. Поддержка форматов видео, HDR и звука зависит от декодеров телевизора. В этой версии IPTV и торренты не работают в фоне.

Поиск обращается к внешним источникам, а торрент-клиент обменивается фрагментами с другими участниками. Настройки, избранное и история хранятся локально. Интерфейс загружается из APK; внешний HTML и сторонние скрипты в нём не запускаются.

## Сборка из исходников

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35. Создайте `local.properties` со строкой `sdk.dir=/абсолютный/путь/к/android-sdk` либо настройте `ANDROID_HOME`.

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintRelease
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. В репозитории закреплены версии зависимостей и Gradle Wrapper 8.11.1. JVM-тест торрента настроен для macOS ARM64: скачайте официальный `TorrServer-darwin-arm64` MatriX.147 в `../.toolchain/downloads/` относительно проекта и сделайте файл исполняемым. Его путь указан в `app/build.gradle`. Android-тест с локальным видео: `./gradlew :app:connectedDebugAndroidTest` при подключённом тестовом ARM64-устройстве.

Переданный release APK подписан отдельным локальным ключом. Ключ и пароли не включены в архив исходников. Для выпуска обновления с сохранением установленного приложения используйте оригинальную папку `.signing` в рабочем проекте и `./gradlew :app:assembleRelease`. Сохраните эту папку в безопасном месте. APK, подписанный другим ключом, нельзя установить поверх этой версии без удаления приложения и его данных.
