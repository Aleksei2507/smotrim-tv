# История изменений Смотрим TV

## Сборка 0.6.8

- APK стал меньше: 57 МБ вместо 70. При сборке теперь сжимается код приложения, а встроенные обложки уменьшены до 960×540, как обложки каталога. Обновление скачивается быстрее и занимает меньше места на телевизоре.
- Встроенные обложки занимают меньше памяти на экране. Четыре из них были в формате WebP с расширением .jpg, теперь это обычные JPEG.
- Функции и настройки не менялись.

Проверено: сборка с R8, Android lint без ошибок, 86 из 88 JVM-тестов (два торрент-теста требуют локального движка и в этом окружении не запускались). На эмуляторе Android TV — главная, IPTV и проверка обновлений. На TCL пользователь подтвердил просмотр торрента на сборке с R8. Перемотка, сериалы и долгий просмотр отдельно не проверялись.

## Каталог 0.6.7

- Новые карточки добавляются в начало каталога. Обновление описания, озвучки или списка серий не меняет место существующей карточки.
- Жанры фильмов и избранного строятся по данным карточек. Русские и английские названия одного жанра объединяются; доступны все жанры, а не только первые два из подписи.
- Длинная строка жанров прокручивается стрелками пульта, в том числе с очень крупным текстом.

## Исправление 0.6.6 — SD MPEG-4 на Realtek

- Размер раздачи отображается в МБ/ГБ вместо длинного числа байтов, в том числе для сохранённых карточек каталога.
- После ошибки аппаратного декодера Realtek при просмотре SD MPEG-4/Xvid плеер один раз пробует программный декодер. Источник, торрент-буфер и позиция сохраняются; повторного запуска торрент-движка нет.
- Переключение ограничено незашифрованным MPEG-4 размером до 1024×576. AVC, HEVC, Dolby Vision, IPTV и HD/4К продолжают использовать прежний выбор декодера.
- В подробностях ошибки теперь видны формат, разрешение и имя декодера. Исправление не относится к проблеме красных цветов в других раздачах.
- APK установлен на TCL. Автоматическое восстановление проверено на синтетическом ролике с принудительной ошибкой декодера; исходный проблемный файл пользователь проверит позже. Результаты и ограничения — в TESTING.md.

## Изменения 0.6.3

Приложение получает список при запуске и через «Настройки → Обновить список каналов». При сетевой ошибке остаётся сохранённая копия; собственные M3U-плейлисты не заменяются автоматически.
- На проверенных потоках CNN и Bloomberg доступны в 720p, Fox News и MSNBC / MS NOW — в 432p. Доступность внешних потоков может меняться.

## Изменения 0.6.0

- Встроена подборка из 34 русских карточек: 16 фильмов и 18 сериалов/шоу, российские и зарубежные названия вперемешку. Ключи API для неё не нужны.
- В 30 карточках сохранены готовые варианты с признаками русского звука в метаданных раздач. «Смотреть» открывает выбор качества; для сериалов учитываются сезон, серия и границы неполной раздачи. «Найти другие варианты» запускает обычный поиск. Если готовых ссылок нет, поиск включается автоматически.
- Небольшой индекс обновляется с GitHub при запуске с интервалом проверки 4 часа. Настройки позволяют проверить сразу. Подробности загружаются отдельно и проверяются по SHA-256; при сбое остаётся последняя рабочая копия. Каталог можно обновлять без выпуска APK.
- Русские названия, описания и жанры; нумерация «Выживалити» сверена с Пятницей. Если перевод описания эпизода отсутствует, показан номер серии. Доступность и скорость каждой раздачи не гарантируются: они проверяются при подключении.

Схема, ограничения кэша и команда обновления данных: [catalog/README.md](catalog/README.md).

## Изменения 0.5.4

- «Домой» на пульте ставит просмотр на паузу, сохраняя плеер, выбранный файл и подготовленный торрент. Возвращение через значок приложения продолжает этот же сеанс без повторного открытия раздачи. Если пауза была включена вручную, она сохраняется.
- Выход через «Назад» из плеера по-прежнему завершает просмотр и освобождает кэш. Переподключение IPTV не отменяет ручную паузу.
- При пересоздании экрана Android восстанавливает плеер, позицию, файл/серию и состояние паузы из небольшого saved state. Если система выгрузила процесс, поток подключается заново; сохранение готового кэша после выгрузки не гарантируется. Принудительная остановка и перезагрузка телевизора не являются возвратом к сохранённой Activity.

Проверено: 63 JVM-теста, 22 JS-теста и 8 инструментальных тестов на Android TV API 34, включая настоящий Home и возврат через значок. Подробности и ограничения — в TESTING.md.

## Изменения 0.5.3

- Часы плеера обновляются во время просмотра, на паузе и после возвращения панели управления; весь экран для этого не перерисовывается.
- В «Настройки → Буфер видео» добавлена внутренняя память: 256 / 512 МБ или 1 / 2 ГБ. Существующий выбор RAM сохраняется; переход на диск — по выбору пользователя.
- Дисковый кэш хранит отдельные фрагменты, удаляет старые по мере просмотра и очищается при закрытии. После сбоя остатки удаляются при следующем запуске приложения. Размер кэша не увеличивает целевой лимит Go RAM.
- Перед запуском размер уменьшается по доступному месту, оставляя 1 ГБ для системы и ещё 128 МиБ на фрагменты сверх мягкого лимита. Если не помещаются даже 256 МБ, используется RAM с уведомлением. При падении свободного места ниже 128 МиБ просмотр останавливается, кэш очищается.
- В диагностике плеера видно фактическое место хранения и лимит кэша. Большой кэш не означает столько же готового видео впереди и не компенсирует постоянно медленную раздачу.

Проверено: 60 JVM-тестов, включая оба режима реального TorrServer, 22 JS-теста, Android lint без ошибок, подписанная release-сборка и компиляция Android-инструментальных тестов. В браузере проверены часы, выбор хранения и управление стрелками при обычном и очень крупном тексте.

На физическом TCL эта версия требует проверки после установки: скорость накопителя, декодер и общая нагрузка могут отличаться от тестового окружения.

## Исправления 0.5.2

- Русский запрос сохраняется при открытии карточки и выборе серии. Поиск вариантов использует русское название из каталога либо исходный русский запрос, оригинальное название, сезон и серию; дополнительно ищет сезон целиком.

Подпись показывает известный язык по названию раздачи либо «Язык звука не указан». Название на английском само по себе не определяет язык дорожек; проверить их можно в плеере.
- Изменение предпочтений сразу обновляет порядок строк и сохраняет соответствие выбранной строки раздаче.

Это не автоматический перевод: без личного ключа KP/TMDB показываются данные Cinemeta, а полнота русских описаний зависит от подключённого каталога. Сообщение о недоступности Cinemeta больше не предлагает проверить несуществующий ключ этого сервиса.

Проверено: 56 JVM-тестов без нативного TorrentStreamingTest, 22 JS-теста, release-сборка, Android lint без ошибок и браузерный сценарий поиска/выбора серии. Физический TCL и подключение каталогов с личными ключами в этом запуске не проверялись.

Приложение показывает данные источника, не придумывая недостающие серии. Для другого покрытия и русских описаний можно подключить каталоги в настройках; полнота зависит от них.

## Новое в 0.5.0

- Поиск открывает карточки фильмов, сериалов и шоу: постер, год и краткое описание. Варианты просмотра появляются после «Смотреть» или выбора серии. Отдельный поиск по раздачам сохранён.
- Добавлены фильтры по типу и стране, загрузка следующих результатов и возврат к выбранной карточке без сброса страницы.
- Добавлены адаптеры Kinopoisk API Unofficial и TMDB. Популярные списки подключённых каталогов чередуются, одинаковые произведения объединяются. Российская популярность и страна производства учитываются отдельно.
- На странице сериала появились постер, описания серий и «Продолжить». Поиск раздач использует основное и оригинальное название, сезон и номер серии; поддерживаются сборники сезонов.
- Прогресс связывается с произведением и серией, а не с языком названия или выбранной раздачей.

**Подключение каталогов:** «Настройки → Каталоги фильмов и сериалов». Для русского каталога нужен личный ключ Kinopoisk API Unofficial; TMDB принимает API key или Read Access Token. Ключ проверяется и хранится только на телевизоре, в APK и исходниках его нет. Без ключей доступен Cinemeta, где российских шоу и русских описаний может не быть. Доступность, состав, описания серий и лимиты зависят от источников.

Проверено: 49 JVM-тестов без нативного TorrentStreamingTest, 19 JS-тестов, сборка release и lint без ошибок, управление пультом и состояния поиска на браузерном стенде 1280×720 с крупным текстом. Живой поиск Cinemeta проверен. Подключение к Kinopoisk API Unofficial/TMDB с личными ключами ещё не проверено: ключи не предоставлены. Повтор полного JVM-прогона завершился с exit 139 тестового процесса, поэтому TorrentStreamingTest исключён из финального прогона; остальные 49 тестов прошли. Android TV эмулятор падает при загрузке; установка обновления и просмотр на физическом TCL в этом запуске не проверены.

## Исправления 0.4.1

- Снижен расход памяти плеера: целевой размер дополнительного буфера Media3 — 24 МиБ. Это не лимит памяти всего приложения: торрент, декодер, графика и интерфейс используют её отдельно.
- В «Настройки → Буфер видео» добавлены 64 МБ. Автоматический выбор оставляет больше запаса Android и плееру. При вылетах начните с 64–96 МБ.
- При завершении процесса интерфейса WebView просмотр останавливается, а приложение предлагает восстановить интерфейс. Сохранённый прогресс можно открыть снова.
- «Настройки → Память и сбои» показывает доступную RAM и последнюю причину завершения, если Android её предоставил. Эти сведения хранятся только на телевизоре.
- Вместо занятого кэша в центре плеера показан запас видео перед текущей позицией в секундах. «Ещё → Загрузка и буфер» отдельно показывает заполнение торрент-кэша. Полный кэш не гарантирует, что следующий фрагмент уже готов.
- Исправлены зависшая надпись «Подключаемся к раздающим» после начала просмотра и кнопка паузы во время подгрузки.

Увеличение буфера не ускоряет медленную раздачу. При одном подключении и скорости 0,3 МБ/с тяжёлый 4К-файл может останавливаться даже с полным кэшем. Попробуйте другую раздачу или меньший размер видео. Проверки выполнены на эмуляторе; устранение всех причин вылетов на физическом TCL не подтверждено.


## Новое в 0.4.0

- **Сериалы → название → сезон → серия.** Отдельный каталог и поиск карточек Cinemeta. Сезоны, названия и даты серий загружаются независимо от файлов в торренте. Спецвыпуски вынесены отдельно; будущие серии показываются с датой и недоступны для запуска.
- Выбранная серия ищется среди отдельных выпусков и сезонов целиком. Явно другой сезон/номер исключается; результаты без понятного номера помечены для проверки. После подключения автоматически выбирается только единственный совпавший файл. При неоднозначности приложение предлагает выбор вручную.
- Прогресс и отметки просмотра сохраняются для каждой серии по IMDb ID, даже при смене раздачи. На главной остаётся одна карточка продолжения сериала. После конца серии предлагается следующая по каталогу; если её нет в текущей раздаче, можно найти другие варианты.
- **Настройки → Текст и выделение:** обычный, крупный и очень крупный текст; усиленная рамка выбранной кнопки; уменьшение анимаций. Изменения видны сразу и сохраняются после перезапуска. Системные окна Android и размер субтитров регулируются отдельно.

Каталог не гарантирует наличие всех сериалов и раздач. Если карточка не найдена, используйте «Искать по торрентам» или режим поиска «Фильмы». Имена, переводы и даты зависят от источника; при поиске по короткому названию могут встречаться одноимённые проекты. Карточки серий кэшируются на сутки, до 30 сериалов; при сбое сети доступна сохранённая карточка с предупреждением. Старые записи из поиска по торрентам продолжают работать, но не объединяются с новой IMDb-карточкой автоматически.

## Возможности 0.3.0

Сезоны и серии из имён видеофайлов в раздаче; текущая серия и действия с историей; сохраняемый язык звука и субтитры; подтверждаемая перемотка; предпочтения качества; XMLTV-программа; CH+/CH− и предыдущий канал; таймер сна; диагностика буфера; порядок каналов и избранных с пульта.

Порядок: «Телеканалы → Порядок каналов». Для избранных сначала выберите фильтр «Избранные». OK включает перенос, ↑↓ двигают на 1, ←→ на 10, повторный OK закрепляет позицию. После закрепления → сразу переводит к кнопке сохранения, ↑ возвращает к выбранному каналу. «Назад» во время переноса отменяет его; «Сохранить порядок» применяет весь список. Обновление ссылок встроенного плейлиста сохраняет порядок по ID каналов.

Программа передач: источник по умолчанию https://epg.pw/xmltv/epg_RU.xml.gz; собственный URL задаётся в настройках. Сохраняются только актуальные передачи ближайших суток, обновление не чаще раза в 6 часов или вручную. XMLTV должен содержать start/stop с часовым поясом; DTD и внешние сущности запрещены. Сжатый ответ ограничен 12 МиБ, распакованный — 128 МиБ. Совпадения по ID/названию консервативные; неизвестное расписание не угадывается. При сетевой ошибке показывается оставшаяся актуальная часть кэша.

Серии распознаются по S01E02, 1x02, «Сезон / Серия», папкам сезона и номерам файлов. Без этих признаков файл остаётся в «Других видео». Для видео, открытого напрямую из поиска по торрентам, следующая серия выбирается среди файлов текущей раздачи. В новом каталоге «Сериалы» доступен поиск следующей серии в других раздачах. Языковые предпочтения не гарантируют наличие нужной дорожки.

Таймер останавливает просмотр и торрент-движок, не выключает ТВ. При уходе из приложения просмотр и таймер прекращаются. Рекомендации на штатном домашнем экране Google TV в эту версию не входят.
