# Подборка Смотрим без отдельного сервера

Публичный адрес: https://raw.githubusercontent.com/Aleksei2507/smotrim-tv/main/catalog/v1/index.json

В APK есть начальная копия подборки. При запуске приложение проверяет обновление на GitHub, не чаще одного раза в четыре часа; кнопка в «Настройки → Каталоги фильмов и сериалов» проверяет сразу. HTTP ETag позволяет не скачивать неизменившийся список. Полная карточка загружается только при открытии. При сбое остаётся последняя проверенная копия. Это обновление данных, переустановка APK не нужна.

`v1/index.json` содержит компактные карточки, ревизию и SHA-256 каждого подробного файла. `v1/cards/<sha256>.json` — неизменяемые подробности: русское описание, сезоны/серии и готовые magnet-варианты. Старые опубликованные файлы нельзя удалять сразу: на них могут ссылаться сохранённые списки телевизоров. Кэш на телевизоре ограничен 8 МиБ и 40 карточками; список — 2 МиБ / 3000 карточек, подробности — 512 КиБ. Эти ограничения защищают память, а не являются ограничением GitHub.

Выборка редакционная, смешивает российские и зарубежные популярные/высоко оценённые произведения. Это не официальный рейтинг IMDb или Кинопоиска и не вся база кино. Источники для отбора записаны в `curated/titles.json`. Русские краткие описания написаны для этой подборки. Ссылки на постеры и базовые сведения получены из публичного Cinemeta; источники исправлений серий записаны в карточках. При отсутствии переведённого описания эпизода показывается «Серия N» без выдуманного содержания. Нумерация «Выживалити» сверена с официальным сайтом Пятницы.

Готовые варианты выбираются по совпадению названия, года фильма, сезона/серии и признакам русского звука в метаданных раздачи. Русские субтитры не считаются русской озвучкой. Для российских произведений допускается оригинальный русский звук. Проверка метаданных не является проверкой каждой звуковой дорожки и не гарантирует доступность пиров. Сохранённое количество раздающих намеренно не показывается как текущее. При отсутствии подходящего варианта используется обычный поиск. Кнопка «Найти другие варианты» всегда запускает свежий поиск, обходя сохранённые ссылки.

## Обновление

1. Отредактировать `curated/titles.json`: канонический IMDb ID, русский заголовок/описание, тип и происхождение. `year` исправляет год зарубежного проката; `searchName` задаёт удобный запрос; `aliases` содержит проверенные названия. `defaultSeason` допускается только для подтверждённого односезонного сериала с раздачами без номера сезона.
2. Получить сырые результаты: `python3 tools/refresh_catalog.py --raw /tmp/smotrim-catalog`. Нужен JDK 17+. Зависимости JSON и Jsoup загружаются из Maven Central в указанную временную папку. Повторная попытка для отдельных карточек: `--retry tt10466872,tt31531192`. Сырые результаты и сторонние английские описания не публикуются.
3. Проверить идентичность произведений, год, язык и сезоны. Ручные исправления серий/описаний — `curated/details.json`. Ссылки на подтверждающие источники хранить в `episodeSources`. Не подменять отсутствующие данные догадками.
4. `python3 tools/build_catalog.py --raw /tmp/smotrim-catalog --bundle` создаёт новую монотонно возрастающую ревизию, JSON и копию в APK. Для обновления только данных `--bundle` необязателен. Старые публичные карточки сохраняются, в APK попадает только текущая версия.
5. `python3 tools/build_catalog.py --check` и `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools -p test_build_catalog.py`.
6. Опубликовать `catalog/v1` в ветке `main`. Индекс и все новые файлы должны попадать в один коммит. Телевизор проверяет SHA-256, схему, идентичность карточки и границы размеров; неподходящий ответ не заменяет последнюю рабочую копию.

Обновление подборки пока выполняется этой командой, автоматически по расписанию данные не собираются. Токены GitHub, API-ключи и история просмотров в каталог не попадают.
