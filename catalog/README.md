# Подборка Смотрим без отдельного сервера

Публичный адрес: https://raw.githubusercontent.com/Aleksei2507/smotrim-tv/main/catalog/v1/index.json

В APK есть начальная копия подборки. При запуске приложение проверяет обновление на GitHub, не чаще одного раза в четыре часа; кнопка в «Настройки → Каталоги фильмов и сериалов» проверяет сразу. HTTP ETag позволяет не скачивать неизменившийся список. Полная карточка загружается только при открытии. При сбое остаётся последняя проверенная копия. Это обновление данных, переустановка APK не нужна.

`v1/index.json` содержит компактные карточки, ревизию и SHA-256 каждого подробного файла. `v1/cards/<sha256>.json` — неизменяемые подробности: русское описание, сезоны/серии и готовые magnet-варианты. Старые опубликованные файлы нельзя удалять сразу: на них могут ссылаться сохранённые списки телевизоров. Кэш на телевизоре ограничен 8 МиБ и 40 карточками; список — 2 МиБ / 3000 карточек, подробности — 512 КиБ. Эти ограничения защищают память, а не являются ограничением GitHub.

Начальная выборка редакционная, смешивает российские и зарубежные популярные/высоко оценённые произведения. Это не официальный рейтинг IMDb или Кинопоиска и не вся база кино. Источники для отбора записаны в `curated/titles.json`. Русские краткие описания написаны для этой подборки. Ссылки на постеры и базовые сведения получены из публичного Cinemeta; источники исправлений серий записаны в карточках. При отсутствии переведённого описания эпизода показывается «Серия N» без выдуманного содержания. Нумерация «Выживалити» сверена с официальным сайтом Пятницы.

Готовые варианты выбираются по совпадению названия, года фильма, сезона/серии и признакам русского звука в метаданных раздачи. Русские субтитры не считаются русской озвучкой. Для российских произведений допускается оригинальный русский звук. Проверка метаданных не является проверкой каждой звуковой дорожки и не гарантирует доступность пиров. Сохранённое количество раздающих намеренно не показывается как текущее. При отсутствии подходящего варианта используется обычный поиск. Кнопка «Найти другие варианты» всегда запускает свежий поиск, обходя сохранённые ссылки.

## Автоматическое пополнение

Workflow [«Обновление каталога»](https://github.com/Aleksei2507/smotrim-tv/actions/workflows/catalog.yml) запускается ежедневно около 03:35 по Москве (00:35 UTC). GitHub может задержать запуск. Кнопка **Run workflow** запускает проверку сразу. Отдельный сервер и личные API-ключи не требуются; право записи в этот репозиторий выдаёт стандартный временный `GITHUB_TOKEN` задания.

`tools/auto_catalog.py` смешивает популярные фильмы/сериалы Cinemeta и недавно обновлённые российские произведения Wikidata. Русское название и краткая справка берутся из Wikidata **по точному IMDb ID**; сведения Wikidata распространяются на условиях [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing). Это короткая справка, не обязательно развёрнутый сюжет. Редакторские описания начальной подборки сохраняются.

Новая карточка публикуется, только если найдены русские название и описание, постер, совпадающие название/год и хотя бы одна раздача с признаками русского звука и раздающими. Для сериала также нужен список серий и известный сезон раздачи. Ссылки проверяются по данным JacRed; наличие русских субтитров отдельно не подходит. Отсутствующий перевод не подменяется транслитом. Поэтому каталог растёт постепенно и не обещает все новинки в день премьеры. При сомнениях карточка пропускается; ручной поиск в приложении остаётся доступен.

За запуск проверяются до 24 кандидатов, добавляются до 8 карточек, обновляются 6 существующих карточек по очереди. Для сериалов пополняются сезоны/серии, сохраняются ручные исправления `curated/details.json`. Пустой или частичный ответ не удаляет сохранённые варианты других сезонов/качеств. Неудачный кандидат проверяется снова не раньше чем через 3 дня. Первый предел роста — 1200 карточек и 2 МиБ индекса; перед дальнейшим ростом потребуется разделить индекс на страницы. Учёт попыток в `automation/state.json` содержит только публичные ID и даты, без истории пользователей.

Перед публикацией проходят тесты, проверка схемы, размеров, диапазонов серий и SHA-256. Все новые объекты и индекс публикуются одним коммитом; старые объекты остаются доступны. Если сервисы недоступны или проверка не прошла, последний рабочий каталог сохраняется. В отчёте запуска видны добавленные карточки и причины пропуска. APK не пересобирается, начальная встроенная копия не меняется.

Локальный запуск: `PYTHONDONTWRITEBYTECODE=1 python3 tools/auto_catalog.py`; для отдельной копии каталога — `--root /path/to/copy`. Требуется Python 3.9+ без сторонних библиотек. Все проверки: `python3 -m unittest discover -s tools -p 'test_*catalog.py'`. GitHub может отключить расписание публичного репозитория после 60 дней без активности; успешные ежедневные коммиты поддерживают активность, а после длительной паузы задание можно включить на странице Actions.

## Редакторское обновление

1. Отредактировать `curated/titles.json`: канонический IMDb ID, русский заголовок/описание, тип и происхождение. `year` исправляет год зарубежного проката; `searchName` задаёт удобный запрос; `aliases` содержит проверенные названия. `defaultSeason` допускается только для подтверждённого односезонного сериала с раздачами без номера сезона.
2. Получить сырые результаты: `python3 tools/refresh_catalog.py --raw /tmp/smotrim-catalog`. Нужен JDK 17+. Зависимости JSON и Jsoup загружаются из Maven Central в указанную временную папку. Повторная попытка для отдельных карточек: `--retry tt10466872,tt31531192`. Сырые результаты и сторонние английские описания не публикуются.
3. Проверить идентичность произведений, год, язык и сезоны. Ручные исправления серий/описаний — `curated/details.json`. Ссылки на подтверждающие источники хранить в `episodeSources`. Не подменять отсутствующие данные догадками.
4. `python3 tools/build_catalog.py --raw /tmp/smotrim-catalog --bundle` создаёт новую монотонно возрастающую ревизию, JSON и копию в APK. Для обновления только данных `--bundle` необязателен. Старые публичные карточки сохраняются, в APK попадает только текущая версия.
5. `python3 tools/build_catalog.py --check` и `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools -p test_build_catalog.py`.
6. Опубликовать `catalog/v1` в ветке `main`. Индекс и все новые файлы должны попадать в один коммит. Телевизор проверяет SHA-256, схему, идентичность карточки и границы размеров; неподходящий ответ не заменяет последнюю рабочую копию.

Редакторская пересборка сохраняет автоматически добавленные карточки. Токены GitHub, API-ключи и история просмотров в каталог не попадают.
