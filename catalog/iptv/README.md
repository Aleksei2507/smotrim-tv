# Телеканалы Смотрим

С версии 0.6.3 стандартный список загружается из [channels.m3u](channels.m3u) в этом репозитории. Публичный адрес: https://raw.githubusercontent.com/Aleksei2507/smotrim-tv/main/catalog/iptv/channels.m3u

Приложение проверяет список при запуске; вручную — «Настройки → Обновить список каналов». Обновление не прерывает просмотр. Последняя загруженная копия сохраняется на телевизоре; при сетевой ошибке или пустом ответе она не заменяется. На первой установке используется встроенная копия. Собственный M3U-плейлист не заменяется автоматически; ручное обновление стандартного списка возвращает список Смотрим.

Для добавления канала или исправления его потока измените `channels.m3u` и опубликуйте коммит в `main`. Пересборка APK не нужна. GitHub может несколько минут отдавать предыдущую копию. Используется стандартный M3U, который приложение уже поддерживает, поэтому отдельный JSON и сервер не требуются. Сейчас список занимает менее 256 КиБ; предел ответа в приложении — 4 МиБ.

Каждому каналу нужны `tvg-id`, название, `group-title` и HTTP(S)-адрес потока. Логотип задаётся через `tvg-logo`; дополнительные заголовки — `#EXTVLCOPT:http-user-agent` и `#EXTVLCOPT:http-referrer`. Не публикуйте пароли, ключи и приватные адреса. При замене ссылки сохраняйте `tvg-id`: он используется для переноса избранного и порядка каналов. Для разных региональных эфиров нужны разные ID.

Перед публикацией проверьте M3U, вложенный медиаплейлист и видеофрагмент изменённых потоков. Изменение стандартного списка не означает автоматической проверки работоспособности всех каналов. При выпуске нового APK обновите также начальную копию `app/src/main/assets/channels.m3u` и данные браузерного предпросмотра `preview-channels.json`.

Исходный русскоязычный список и резервные потоки: [iptv-org](https://github.com/iptv-org/iptv). CNN, Fox News и MSNBC / MS NOW добавлены из опубликованных там потоков; Bloomberg TV — через публичный адрес Bloomberg. Проверка 25 октября 2026: видеофрагменты всех четырёх декодируются; CNN и Bloomberg — 720p, Fox News и MSNBC / MS NOW — 432p. Доступность зависит от внешнего провайдера и сети телевизора.
